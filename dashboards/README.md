# Power BI dashboard

Open `hotel-cancellation.pbix` in Power BI Desktop. The supplied file contains two report pages: **Dashboard** and **Action List**.

The file is preserved as supplied. A refresh may require updating local CSV paths through Power Query / Data source settings. The included notebooks generate an earlier scoring version; do not replace the dashboard source with those outputs and assume the final report totals will match.

See [artifact versions](../docs/artifact-versions.md) before refreshing. For a browser-readable overview, use the [final presentation](../presentations/final-presentation.pdf) and [final report](../reports/final-report.pdf).
